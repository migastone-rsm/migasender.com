## 🚀 Installazione e Deploy

### Metodo 1: FTP/SFTP (CONSIGLIATO)

1. **Scarica tutti i file** del progetto
2. **Connettiti al tuo hosting** via FTP (FileZilla, Cyberduck, etc.)
3. **Carica tutti i file** nella root o in una sottocartella:
   ```
   public_html/              (root)
   o
   public_html/migasender/   (sottocartella)
   ```
4. **Mantieni la struttura** delle cartelle intatta
5. **Configura form-handler.php**:
   - Apri il file
   - Modifica email destinazione (riga 28):
     ```php
     define('MIGASENDER_ADMIN_EMAIL', 'tuaemail@example.com');
     ```
6. **Imposta permessi** (se necessario):
   ```
   chmod 644 index.html
   chmod 644 css/style.css
   chmod 644 js/main.js
   chmod 755 form-handler.php
   ```
7. **Visita il sito!** 🎉

### Metodo 2: cPanel File Manager

1. Login a cPanel
2. File Manager → public_html
3. Upload → Seleziona tutti i file
4. Estrai (se ZIP)
5. Configura form-handler.php
6. Done!

### Metodo 3: Git Deploy

```bash
# Clone o pull del repository
git clone [your-repo-url]
cd migasender-website

# Configura email in form-handler.php
nano form-handler.php

# Deploy automatico (se configurato)
git push origin main
```

### Alternative Email (se mail() non funziona):

#### Opzione A: PHPMailer con SMTP

```php
// Installa PHPMailer

$mail->isSMTP();
$mail->Host = 'smtp.gmail.com';
$mail->SMTPAuth = true;
$mail->Username = 'your@gmail.com';
$mail->Password = 'your-app-password';
$mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
```

## 🐛 Troubleshooting

### Form non invia email

**Problema:** Form submitted ma nessuna email ricevuta

**Soluzioni:**
1. Verifica che PHP mail() funzioni:
   ```php
   <?php
   mail('test@example.com', 'Test', 'Test message');
   echo 'Email inviata!';
   ?>
   ```
2. Controlla spam/junk folder
3. Verifica log errori PHP: `error_log`
4. Usa SMTP invece di mail() (vedi sopra)

### CSS/JS non si caricano

**Problema:** Stili o JavaScript non funzionano

**Soluzioni:**
1. Verifica path file (console browser F12)
2. Controlla permessi file (644)
3. Clear cache browser (Ctrl+F5)
4. Verifica .htaccess non blocchi file

### Mobile menu non funziona

**Problema:** Hamburger menu non si apre

**Soluzioni:**
1. Verifica main.js caricato (console)
2. Controlla errori JavaScript (F12)
3. Testa su browser diversi
4. Disabilita estensioni browser

### Notifiche non appaiono

**Problema:** Form submit ma nessuna notifica toast

**Soluzioni:**
1. Verifica console JavaScript (F12)
2. Controlla z-index conflitti CSS
3. Testa con notification forzata
4. Verifica fetch() funzionante
